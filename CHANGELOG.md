# Changelog

## [1.7.2] - 2026-10-22

### Fixed

- 1.7.1 поднимал собственный EventSystem симуляции всегда, и если пауза рекламы не выключала EventSystem сцены (пункт Disable EventSystem снят), в сцене оказывались два активных EventSystem: Unity писал `There are 2 event systems in the scene`, а первый клик по окну результата часто терялся. Теперь свой EventSystem включается только когда другого активного в сцене нет, поэтому активным всегда остаётся ровно один.

## [1.7.1] - 2026-10-22

### Fixed

- Клики по окну симуляции (выбор результата рекламы, Ask every time) иногда не проходили. Реклама берёт паузу до показа окна, а пауза выключает EventSystem сцены, на который опирался uGUI-оверлей. Теперь оверлей поднимает собственный EventSystem (включён только пока окно показано) и помечен так, что пауза его не трогает.
- Окно симуляции иногда схлопывалось: `LateUpdate` пересчитывал высоту карточки от размеров холста и контента, а когда вкладка Game не в фокусе или на первом кадре они приходят нулевыми. Пересчёт пропускается, пока размеры не готовы.

## [1.7.0] - 2026-10-21

### Changed

- На YouTube состояние звука перечитывается при возврате на вкладку: мост слушает `visibilitychange` (на видимой странице), `pageshow` и `focus` окна и переспрашивает `ytgame.system.isAudioEnabled()`. Так звук восстанавливается, если площадка включила его, пока вкладку не смотрели, как в Playgama Bridge. `visibilitychange` в бандле YouTube снова присутствует, поэтому проверка сертификации YouTube опять отметит Page Visibility API предупреждением.

### Removed

- Убран локальный бэкап сейва в `localStorage`. SDK хранит сейв только на площадке. Удалены `IBackupStorage`, `WebBackupStorage`, `WebStorage` и jslib-функции `JTLSDK_WriteBackup` / `ReadBackup` / `ClearBackup`; `SdkInstance.BackupStorage` больше нет. Сохранение перед скрытием вкладки и по платформенной паузе осталось, но без резервной копии: при обрыве последней записи теряются изменения после последнего успешного сохранения на площадку.

## [1.6.1] - 2026-10-09

### Fixed

- Молчащую игру на YouTube теперь видно в консоли. SDK ставит `AudioListener.volume = 0`, пока площадка сообщает, что звук выключен, но об этом не было ни строки в логе: игра выглядела как сломанная, хотя источники играли. Теперь при старте пишется, что звук выключен площадкой, и каждое изменение этого состояния тоже логируется.
- Состояние звука площадки перечитывается у YouTube при возобновлении и сразу после `gameReady`, а не только по `onAudioEnabledChange`. Если площадка включила звук в момент, когда колбэк ещё не был повешен, игра больше не остаётся немой до конца сессии.

## [1.6.0] - 2026-10-09

### Added

- Пауза останавливает рендеринг: `OnDemandRendering.renderFrameInterval` уходит в большое значение и возвращается на прежнее при возобновлении. Галка Stop rendering в разделе Pause, по умолчанию включена.
- Пауза блокирует ввод на уровне страницы: поверх холста поднимается прозрачный слой, поэтому события мыши и касаний до движка не доходят вовсе. Галка Block input, по умолчанию включена. Это важно, потому что `Time.timeScale = 0` не останавливает `Update`, и игра, читающая `UnityEngine.Input` напрямую, иначе продолжала бы работать на паузе; теперь проверять паузу в коде игры не нужно.
- При снятии паузы вызывается `Input.ResetInputAxes()`, чтобы нажатие, которым сняли паузу, не утекло в игру.

### Changed

- Слой блокировки живёт в шаблоне SDK (`#jtlsdk-input-block`), а C# дёргает его через `JTLSDK_BlockInput` и `window.JTLSDK_PAGE.blockInput`. Со своим шаблоном страницы метод нужно реализовать, иначе блокировка просто не сработает. Клавиатура слоем не перехватывается, холст только теряет фокус.

## [1.5.0] - 2026-10-09

### Changed

- Фиксированные пропорции холста применяются только тогда, когда форма окна им противоречит. Портретная игра 9/16 заполняет портретное окно целиком, а в ландшафтном зажимается по высоте и центрируется; для 16/9 всё наоборот. Раньше пропорции держались в обеих ориентациях, поэтому в портретном окне, которое чуть выше 9/16, появлялись поля сверху и снизу. Так же сделано в YT-шаблоне, который прошёл проверку YouTube.
- В карточке Canvas раздела Template появилась подпись, объясняющая это правило.

## [1.4.2] - 2026-10-09

### Fixed

- `JTLSDK.Version` отстал от версии пакета: в коде оставалось 1.1.0. Из-за этого workflow Release падал на проверке совпадения и не публиковал релизы с 1.1.1, а кнопка обновления в окне SDK читает именно релизы и показывала последней 1.1.0. Константа приведена к версии пакета, добавлен тест, который сверяет её с `package.json`.

## [1.4.1] - 2026-10-09

### Fixed

- В мост YouTube больше не попадает Page Visibility API. Площадка требует вести паузу только через `ytgame.system.onPause` и `onResume`, а проверки сборки ищут в бандле сами строки `visibilitychange`, `document.hidden` и `visibilityState`, поэтому рантайм-флага было бы мало: слушатель переехал из общего ядра в адаптер Яндекса, и в сборку YouTube его текст не попадает вовсе. Паузой он не управлял и раньше, через него уходил только сейв перед скрытием вкладки.
- Чтобы на YouTube сейв не потерялся при сворачивании, изменённый документ сохраняется по платформенной паузе. На Яндексе то же самое срабатывает на паузе во время рекламы. Полный сброс с резервной копией в `localStorage` по-прежнему идёт по `pagehide`, он остался на обеих площадках.

## [1.4.0] - 2026-09-29

### Changed

- Порядок строк в карточке Project settings повторяет блок WebGL Settings в Player Settings: Enable Exceptions, Compression Format, Name Files As Hashes, Data Caching, Debug Symbols, Decompression Fallback, дальше идут Managed Stripping Level, Run In Background и Memory Size.
- Debug Symbols стал выпадающим списком Off, External, Embedded вместо галки. Галка умела только Off и External, а Embedded выбрать было нельзя. `PlayerSettingsPreset.DebugSymbols` теперь `DebugSymbolMode`, а не `bool`; в конфигурациях старое значение переезжает само, потому что выключено это Off, а включено External.
- В разделе Build список Debug Symbols переехал в блок Runtime к Managed Stripping и Enable Exceptions.

### Added

- В пресет добавлена строка Name Files As Hashes. Раньше эта галка в разделе Build писала прямо в Player Settings мимо конфигурации, теперь она часть пресета, как соседние поля. Галка Apply у неё по умолчанию снята, поэтому обновление ничего не перезапишет.

## [1.3.0] - 2026-09-29

### Added

- В пресете конфигурации появилась строка Enable Exceptions: значения как в Unity (None, Explicitly Thrown Exceptions Only, Full Without Stacktrace, Full With Stacktrace). Стоит первой, над Compression Format, как в Publishing Settings. Тот же список продублирован в разделе Build, блок Runtime.
- Галка Apply у этой строки по умолчанию снята, как у Memory Size: SDK не трогает `PlayerSettings.WebGL.exceptionSupport`, пока вы её не поставите, поэтому обновление не перезапишет значение в существующих проектах. У новых конфигураций в пресет кладётся Explicitly Thrown Exceptions Only.

## [1.2.0] - 2026-09-25

### Added

- У конфигурации появилось поле Yandex Metrica counter: раздел Configurations, карточка Analytics. Счётчик читается модулем `com.jtlstudio.sdk.analytics`, который шлёт в него цели; пустое поле означает, что цели не отправляются.
- В каталоге модулей появился Analytics.

## [1.1.1] - 2026-09-24

### Fixed

- Список модулей отваливался с `403 Forbidden`: он и версии модулей читались через GitHub REST API, а тот даёт 60 анонимных запросов в час на адрес, и каждая перекомпиляция тратила несколько. Теперь `modules.json` берётся с `raw.githubusercontent.com`, а версии модулей из ленты тегов `github.com/<repo>/tags.atom` - у этих адресов такого лимита нет.
- Если список не скачался, тулкит показывает модули из `modules.json`, который лежит в самом пакете, а не пустую карточку с ошибкой.
- Проверка релизов SDK больше не ходит в сеть после каждой перекомпиляции: результат живёт час, как и было задумано. При исчерпанном лимите вместо `403 Forbidden` пишется, что GitHub разрешает 60 анонимных запросов в час.

## [1.1.0] - 2026-09-24

### Added

- В разделе Package Manager у модулей появились логотипы и кнопка обновления. Логотип берётся из самого модуля (`Editor/Logo.png`), пока его нет - показывается логотип шаблона. Новая версия ищется по тегам репозитория модуля, поэтому релизы для модулей заводить не обязательно; у встроенных и локальных модулей кнопки нет.

## [1.0.0] - 2026-09-23

Первый публичный выпуск.

- Один API для Яндекс Игр, YouTube Playables и редактора: реклама, покупки, облачные сохранения, языки, пауза, лидерборды, флаги, игрок, площадка, устройство, время, звук, отзыв, ярлык игры, ссылки.
- Окно `JTL SDK › Toolkit`: конфигурации площадок, сборка с проверками, симуляция в редакторе, шаблон загрузочного экрана, каталог модулей, анализатор кода.
- Симуляция в редакторе отвечает за площадку: реклама, покупки, сейвы, лидерборды, флаги, язык, устройство.
- Шаблон WebGL: логотип, фоны, прогресс-бар, текст загрузки, фиксация пропорций, pixel ratio.
- API работает только после `JTLSDK.Create()`; обращение до запуска и после остановки бросает исключение.
- Модули ставятся из раздела Package Manager по каталогу `modules.json`.
